# UI plan
---
## Main screen

The UI will open will 3 sections. The first section will be the largest and will take up the majority of the left size of the window. It will contain all teams which have a rating calculated by the dataset, this section is where you select which 20 teams (or possibly more) will make up the league season you wish to simulate. The second section will take up a portion of the right size of the screen, it will contain conditions for what to simulate for (what champion, what relegations, etc), this will then run the simulation until said conditions are satisfied by one, which will then be displayed. Finally, the third section will be the bottom right of the window, which will simply have a button to begin simulating the season.

---
## Results screen

After simulating has concluded, the resulting table will be displayed in on the screen, the top left will have a return to main screen button, but each position in the table will be a button which can be clicked on to see the results of each game with that team. For example, if Tottenham Hotspur won the league, and you clicked on them, it would show the results of all games which involved Tottenham.

---

## Further additions

- During simulations, a progress flash up screen showing what simulation iteration, best match so far, etc

- Clear selected teams button

- Potentially on the result screen, when clicking on a team, also show their ratings

- Potentially a 'max simulations' input
